# Touch LCD 7 — самостоятельное демо Waveshare

Отдельное ESP-IDF приложение для **ESP32-S3-Touch-LCD-7 Rev1.2, 800×480**.
С showcase используются общий frontend в корне репозитория и компонент NaWServer.
Vue-оболочка и HTTP/WS/SSE общие; project.ts и страница LCD/GT911 — локальное расширение. Соседняя демка не импортируется. RGB использует отдельный GPIO6, Wi-Fi и состояние локальны.

Графика — LVGL8.3.11, два полноэкранных RGB565 framebuffer в PSRAM,
ожидание окончания кадра и VSYNC перед повторным использованием буфера.
Первоначальная правка устранила мерцание при движении пальца. Позднее замечены
редкий пиксельный мусор, полосы и сдвиги: [диагностика и настройки RGB](docs/readme_lcd_stability_ru.md).

Функции: цветовые полосы, сетка, заливки RGB; GT911 и маркер касания;
переключение теста касанием верхней полосы; своя веб-панель, подсветка,
реальные RAM/PSRAM/uptime и WS echo. Экран работает без сети.
Справа в верхней строке LCD показан реальный IPv4 адрес Wi-Fi либо `IP: offline`;
он обновляется при смене адреса и не зашит в прошивку.

Дополнительно для нескольких вкладок:

- Независимые HTTP, CBOR WS и SSE с регулируемыми ограничениями клиентов.
- Резерв TCP-сессий для понятного503 / Retry-After, причины отказа и WS Close1013.
- Восстановление браузерных потоков после временной перегрузки и reload.
- Runtime-таблица лимитов sockets / TCP PCB / HTTP, занятых мест и отказов.
- IDLE0/IDLE1 всегда сверху диспетчера задач при сортировке и поиске.

[Настройки, границы гарантий и диагностика](../../docs/readme_connection_limits_ru.md).
Результаты каждой аппаратной проверки — в руководстве вебки, отдельно от списка фич.

```powershell
$env:PLATFORMIO_CORE_DIR=(Resolve-Path './local/pio-core').Path
cd examples/touch_lcd7
npm.cmd ci --prefix ../.. --no-audit --no-fund
npm.cmd run build --prefix frontend
go run tools/pack-assets/main.go
pio run -e s3 -j 8
```

Для сети создать ignored `main/wifi_secret.hpp` с `NAWSERVER_DEMO_LCD7_WIFI_SSID` и
`NAWSERVER_DEMO_LCD7_WIFI_PASSWORD`. Значения — строки C++; образец с реальными секретами
не хранить в Git. Автоматического копирования из первой демки нет.

После загрузки IP выводится в UART на 115200, веб-панель находится на `/`.
`GET /api/status` возвращает JSON; `POST /api/display` принимает точную строку
`bars`, `grid`, `red`, `green`, `blue`, `on`, `off` и заголовок
`X-LCD7-Command: 1`; 202 означает постановку в очередь, не применение.
`/ws` — binary CBORv2 summary/echo; полная оболочка также использует SSE и защищённые HTTP-команды. LCD-команды /api/display остаются публичными, предназначены
для локального учебного стенда. Отдельные origin/form-команды отвергаются;
это не замена аутентификации или TLS.

В JSON также доступны `renderer`, `framebuffers`, `frame_swaps`, `frame_events`
и `vsyncs`: это реальные счётчики LVGL/RGB драйвера, не оценка отсутствия мерцания.

HTTP и браузерные команды/WS проверены. Локальная копия исходной flash сохранена.
Не применять `pio ... -t upload` к плате с исходной прошивкой без проверки
разметки: текущая таблица совпадает с проверенной S3, но новая плата требует проверки.
