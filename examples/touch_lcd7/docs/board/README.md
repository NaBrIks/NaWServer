## RGB: отдельный вывод GPIO6

Выбран **GPIO6**, выведенный как **AD** на разъём **Sensor AD / J8**.
Соответствие AD→GPIO6 проверено по схеме и
[официальному примеру Sensor AD](https://docs.waveshare.com/docs/ESP32/ESP32-S3/ESP32-S3-Touch-LCD-7/Arduino/Arduino-Sensor-AD-Demo).
В цепи разъёма схема не показывает фильтр или преобразователь, занимающий этот
вывод. Пример не включает ADC, CAN, RS485 или SD.

- AD → DIN внешней WS2812/NeoPixel цепочки;10 пикселей, GRB.
- GND платы и ленты объединить.
- Питание ленты подать согласно её спецификации; контакт3V3 Sensor AD не
  использовать как источник5В. Выход GPIO — логика3.3В; при необходимости
  согласовать уровень DIN с используемой лентой.
- Аналоговый датчик на AD одновременно с RGB DIN не подключать.
- GPIO2 остаётся линией LCD; GPIO8/9 — I²C touch/CH422G.

В firmware есть RMT и SPI варианты, как в прежней демке, но data pin теперь6.
При старте RGB выключен. Готовность драйвера не подтверждает подключение или
физическое свечение. Новая RGB проводка и одновременная работа с LCD пока
не проверены на железе; владелец подключит их позднее.
