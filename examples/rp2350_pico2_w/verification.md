# Работающая RP-демо — 2026-11-02

Адрес проверенного стенда обезличен; HTTP **80**.
Pico 2 W / RP2350 A2, USB serial `<USB_SERIAL>`, сеть `YourSavedWiFiProfile`,
MAC `<DEVICE_MAC>`. Идентификаторы стенда обезличены;
устаревшая динамическая запись с портом 8080 удалена через обычный API.

## Сборка и запуск

- Pico SDK 2.3.1, ARM GCC 14.2.1, FreeRTOS V11.3.3 SMP, **оба ядра активны**.
- Финальный BIN **843352 байта**, ниже границы FS `0x200000`.
  ELF size: text **847444**, data **0**, bss **310484**. Это не самостоятельная
  оценка полного расхода SRAM: heap FreeRTOS уже входит в статические области.
- Физический SRAM 520 КиБ, heap FreeRTOS 192 КиБ. В коротком рабочем запросе
  свободно **157072**, минимум **156776 байт**; newlib heap учитывается отдельно.
- **11 задач**; IDLE0 закреплена за CPU0, IDLE1 — CPU1, таймеры/SDK/веб — CPU0,
  вычислительная задача и постоянный `flash-guard` — CPU1.
- LittleFS смонтирована: **1835008 байт**, занято **188416**. NVS **262144 байта**.
  После сохранения настроек на SMP: NVS generation **19**, boot_count **16**,
  save_count **3**. Имя и Wi-Fi профиль пережили программные обновления.

## Два ядра: реальная короткая проверка

Измерения взяты из runtime counters отдельных idle-задач, не из модели.

| Состояние | CPU0 | CPU1 | Общая |
| --- | ---: | ---: | ---: |
| Перед вычислением | 18,25% | 0,76% | 9,51% |
| Вычисление π на CPU1 | 28,29% | 51,95% | 40,12% |

Трёхсекундная демо-задача завершилась сама, **1669504 итерации**.
Общая = `(CPU0 + CPU1) / 2`, шкала 0–100%; raw sum доступен в `cpu_sum_pct`
на шкале 0–200%. Результаты и affinity задач: `build/dual-core-result.json`.

## HTTP и интерфейс

- `/health`, `/`, JS/CSS gzip-ресурсы, CBOR v2 info/summary/tasks — HTTP 200.
  Ответы CBOR приняты штатными валидаторами общего frontend.
- Общий ESP Vue frontend реально открыт с платы; HTTP, WS и SSE показывают онлайн,
  SSE-счётчик увеличивается, задачи/CPU/RAM/паспорт/сеть/MAC отображаются.
- INFO содержит одновременно CPU0, CPU1 и общую загрузку, три кривые и историю
  обоих ядер в панели задач. Проверены Кремовая/NANO/RU и тёмная тема/EN.
- Штатная страница доступа: все пять проверок PASS (401/401/200/403/401).
- На странице Flash/NVS проверены отказ некорректного имени и успешное сохранение.
  До ошибки, после ошибки и после успеха геометрия панелей совпала:
  `(217,149,574,140.1875)` и `(217,295.1875,574,148.640625)`, scrollTop = 0.
  Автоматических toast-плашек нет; индикатор сообщений занимает постоянное место.
- Финальный вид: `build/ui-dual-core.png`. Runtime-артефакты игнорируются Git.

Программный BOOTSEL через Wi-Fi сработал: `BOOTSEL requested over Wi-Fi` записан
в логе финальной загрузки SMP. Физические кнопки для этих обновлений не требовались.
Отдельные firmware verify/readback/backup и широкие load/soak матрицы не запускались.
Power-cut испытаний NVS и общей SMP-поддержки libc на CPU1 эта проверка не заменяет.
