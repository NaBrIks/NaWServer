# Showcase: постоянная правая панель задач

19.10.2026. Продолжает [общий обзор ресурсов](readme_shell_resources_ru.md).
CPU, RAM и таблица памяти остаются в центре, задачи закреплены справа на **всех**
страницах. Панель начинается под общей шапкой, аналогично левому меню, и не движется
при прокрутке обзора. Список задач обновляется независимо от выбранного раздела.

## Компоновка и управление

- Ширина по умолчанию 480 px. Граница перетаскивается мышью/указателем; клавиши
  ← / → меняют ширину на 10 px, Shift — на 40 px, Home / End выбирают пределы.
  Двойное нажатие возвращает 480 px в пределах доступного места.
- При достаточной ширине окна диапазон 320–720 px; в узком окне предел уменьшается,
  оставляя центральной области место. Фактическая ширина ограничена размером окна.
  Настройка сохраняется в localStorage вместе с темой/плотностью/языком.
- Заголовок и поиск остаются в панели; таблица имеет отдельную прокрутку и липкие
  заголовки. У длинных имён есть ellipsis и полная подсказка, строки не превращаются
  в карточки. Подробности выбранной задачи открываются в нижней части панели.
- Фильтр, сортировка и выбор задачи сохраняются при смене страницы: компонент
  остаётся смонтированным. Пульт симулятора доступен по раскрытию в центральной
  области и не занимает ещё одну правую колонку.

## Строки и обозначения

Состояние занимает одну фиксированную колонку с локальным значком Tabler:

| Состояние | Значок | Цвет |
|---|---|---|
| running | player-play-filled | success |
| ready | circle-check | primary |
| blocked | hourglass | muted |
| suspended | player-pause | muted |
| deleted | x | muted |
| неизвестное | question-mark | muted |

Полное состояние доступно в tooltip и доступном имени. Короткие заголовки:
`%` — CPU, график — история CPU, `P` — приоритет, `C` — ядро, `B` — минимальный
остаток стека с запуска в байтах. Полные пояснения находятся в подсказках и
доступных именах заголовков. Не добавлены отдельные бейджи или строки подписей.

Каждая задача имеет числовой CPU с одним десятичным знаком и собственный мини-график
за последние 60 секунд. **Все CPU-графики фиксированы на 0–100%.** График и число
занимают отдельные постоянные позиции; числа выровнены вправо табличными цифрами.
Ширина мини-графика адаптируется к панели, высота строки остаётся одинаковой.

## Проверки

`vue-tsc` + Vite production, C3 build — PASS. Через CUA проверены все семь разделов,
постоянство положения панели, независимая прокрутка, значки/подсказки, компактная
одинаковая высота строк, правильные края чисел, инспектор httpd и фиксированные
шкалы. Проверяется обновление истории процессов при открытых «Настройках».

На симуляторе дополнительно проверены перезагрузка с сохранённой шириной,
настоящее перетаскивание 480 → 520 px и возврат 480 px, Dark/EN и наличие всех
локальных glyphs. C3 проверяется и в узком окне, без карточек вместо таблицы.
Наблюдённая высота строк в Nano — 24,75 px. Реальные состояния C3 включают ready,
blocked, running и suspended.

Окончательная прошивка: 1 040 864 bytes, `[0x10000,0x10e1e0)`, SHA-256
`a07cd965dea02a2a58fe599bb4a5612a6004d950f0f0e5c7269453dc2a267291`.
Перед записью повторно проверены chip/MAC; vendor hash и boot/IP — PASS. Записан
только app0, без bootloader, partition table, NVS, data, backup или erase-all.
COM10 освобождён. Evidence остаётся ignored в `local/screenshots/*task-dock*`.

Окончательная приёмка: C3 — 21 проверка панели и 13 проверок ресурсов PASS;
симулятор — 22 проверки панели (включая reload) и 13 проверок ресурсов PASS.
На модели также пройдены Home=320 / End=720 / reset=480 px и перетаскивание мышью.
На реальной C3 проверено узкое окно 671 px с панелью 343 px: все числовые
колонки задач помещаются, шкалы остаются фиксированными. Таблица памяти использует
собственную горизонтальную прокрутку. Длинная подпись платы занимает одну строку
с ellipsis и полной подсказкой. Снимок — `local/screenshots/c3-task-dock.png`.

Проверки не являются длительным сетевым soak или worst-case оценкой FreeRTOS stack.
После обновления страницы наблюдались временные ожидания HTTP-данных; проверка
панели выполнялась после появления настоящих задач и обоих потоков WS/SSE.
