# Единый frontend демонстрационных приложений

Дата решения: 20.10.2026. Основание — прямой запрос владельца объединить C3/S3
frontend, взяв текущую S3 версию за основу. Предыдущее требование независимых
копий UI в touch_lcd7 отменено этим решением; firmware остаются независимыми.

Общая Vue-оболочка, компоненты, стили, темы, справки, состояния, транспорт и
валидация API размещаются в корневом frontend/. Установка зависимостей и lock
одни, через npm workspaces. Проекты добавляют типизированный профиль и свои
страницы; специфичные LCD/GT911 типы и оформление остаются в S3 расширении.
GPIO и возможности общих панелей отображаются из данных устройства.

Каждая цель получает собственный dist и встраиваемые ресурсы. Единый исходник
не означает одинаковый образ: S3 добавляет LCD страницу, C3 её не импортирует.
CBOR реестр и поддержка admission выбираются проектом без изменения backend.
Ядро C++ NaWServer не зависит от UI, LCD, Wi-Fi или продуктовых компонентов.

Руководство и проверяемые команды: ../../frontend/README.md.
