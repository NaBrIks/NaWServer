# Прямые строковые ключи CBOR вместо числового реестра

20.10.2026 владелец отверг обязательную числовую схему поверх CBOR и поручил
удалить cbor-keys.json. Выбор CBOR основан на именованных полях, бинарных типах
и встроенном представлении длины, а не на внешнем словаре ID.

Решение: map содержит UTF-8 имя поля непосредственно. Удаляются оба JSON
реестра, сгенерированные C++ заголовки, embedded resource .NET и Vite alias.
C++ Writer/Fields используют строковые имена; JS и .NET кодеки сохраняют
произвольные валидные имена без регистрации. Проверки команд остаются
прикладными, ограничения ресурсов — явными. Числовой legacy не поддерживается.

Это решение отменяет прежнее требование числовых ключей в документации демо
и первоначальное использование отдельных wire-реестров в решении об общем
frontend. Основная библиотека HTTP/WS/SSE по-прежнему не навязывает кодек.

Полные требования: [readme_cbor_requirements_ru.md](../readme_cbor_requirements_ru.md).
