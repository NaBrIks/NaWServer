## Build and runtime boundaries

Compilation against a named SDK does not establish behavior on every board.
Historical measurements remain dated evidence: short ordinary REST 1/2/3-client
acceptance is distinct from reload stress and four-hour observations that recorded
timeouts. No such historical result is promoted to new on-device acceptance by
this publication. Physical display, radio conditions, long-duration reliability,
hard OOM and arbitrary overload remain outside these release checks.

External source/license URLs were reviewed against their upstream repositories;
the link scan does not claim that every historical external URL or fragment anchor
was fetched successfully. Old diagrams/plans remain dated design artifacts, not
automatic code extraction or a substitute for the current API headers.
